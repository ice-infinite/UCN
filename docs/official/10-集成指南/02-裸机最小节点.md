# 裸机最小节点

> 文档级别：`GUIDE`
> 实现状态：`PARTIAL（通用合同已实现，产品 BSP/SDK 需接入）`
> 适用版本：UCN 5.0.0 / Core Wire v5
> 事实源：公共 API、Port/Adapter/Source 实现与测试
> 最近核对：`codex/v5-adaptive-wire@a093862`，2026-08-25
> 硬件状态：部分 ESP32-S3 UART/ESP-NOW；其他平台按正文标注

裸机使用一个 superloop 作为 Protocol Owner：

```text
IRQ: bytes/frame -> BSP ring -> set pending flag
main: drain sources -> node receive -> node/transfer/service step -> sleep
```

所有对象、表、ring 和 TX buffer 静态分配。`now_ms` 必须单调回绕；主循环最大间隔不超过产品配置预算。IRQ 不解析协议、不调用业务 handler、不等待发送完成。

没有中断的介质可在主循环轮询驱动，但仍提交到同一 Source/Adapter 接口。

## 静态对象布局

裸机产品通常定义一个总上下文：

```c
typedef struct product_ucn {
    ucn_node_t node;
    ucn_adapter_rx_queue_t rx_queue;
    ucn_event_runtime_t runtime;
    ucn_stream_source_t uart_source;
    ucn_stream_source_default_storage_t uart_storage;
    ucn_link_t uart_link;
    volatile bool wake_pending;
} product_ucn_t;

static product_ucn_t g_ucn;
```

实际类型可按模块裁剪。所有数组/ring 在编译期确定，避免中断后首次 malloc。

## 初始化顺序

1. 初始化时钟、GPIO、UART/CAN/DMA；
2. 初始化 Port 的时间、随机、持久计数、task/ISR 临界区；
3. 初始化 Node 和 Security/Endpoint；
4. 初始化 Link、Adapter Queue、Source、Event Runtime；
5. 清外设 pending flag，最后打开 RX IRQ/DMA；
6. 发送固定 HELLO 或让 Node step 开始维护。

如果先开 IRQ 再初始化 ring，第一批字节可能写入无效对象。

## ISR 模板

```c
void UART_IRQHandler(void)
{
    uint8_t bytes[DMA_CHUNK];
    size_t n = bsp_uart_read_irq(bytes, sizeof(bytes));

    (void)ucn_stream_source_write_from_isr(&g_ucn.uart_source,
                                           bytes, n);
    g_ucn.wake_pending = true;
}
```

更高性能时 ISR 只更新 DMA producer index，Source 在 Owner 中读取 BSP ring，减少一次 copy。无论哪种方式，ISR 都不调用 `ucn_node_receive()`、日志格式化或业务 handler。

## Superloop

```c
for (;;) {
    bool fallback = timer_due_for_fallback();

    if (g_ucn.wake_pending ||
        ucn_event_runtime_has_pending(&g_ucn.runtime) || fallback) {
        g_ucn.wake_pending = false;
        ucn_event_runtime_run(&g_ucn.runtime, fallback, &run_result);
        run_transfer_and_optional_modules();
    }

    if (!ucn_event_runtime_has_pending(&g_ucn.runtime)) {
        bsp_wait_for_interrupt();
    }
}
```

即使没有 RX，也要在 `UCN_MAX_STEP_INTERVAL_MS` 内执行维护。可用硬件 timer 置 pending，不能让 WFI 无限睡眠。

## 临界区

task/main 与 ISR 共享 ring index 时，分别实现普通和 ISR 临界区。单核 MCU 可短暂关中断，但范围只覆盖 index/拷贝元数据，不覆盖 Frame 解码或 Link send。多核 MCU 还需平台原子/spinlock 与内存屏障。

## TX

Link `send()` 把完整 carrier 放入 TX ring/DMA 并立即返回。队列满时返回 `NO_SPACE`；DMA completion 释放槽并唤醒主循环。不要在主循环中等待每个字节发送完，否则多个 Bearer 无法公平推进。

## 验收

测量最坏 superloop 间隔、ISR 最大时间、ring 峰值、栈余量、持续满速丢帧和断线恢复。关闭所有日志再测一次，避免串口打印掩盖实际性能。
