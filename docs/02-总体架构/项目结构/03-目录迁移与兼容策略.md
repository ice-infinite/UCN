# 目录迁移与兼容策略

## 本轮迁移

内部实现文件从 src 根目录迁移至 core、node、transport、routing、service、ports。CMake 是唯一编译源集真相，调用树和源码地图随路径更新。

## 保持不变

- include/ucn 下的既有公开头路径；
- C API、C99 要求、Wire 协议、Profile 宏、Node 静态布局和 Product Config 覆盖方式；
- ucn_core 与独立 ucn_port_<platform> CMake Target 名称；
- tests 下既有文件路径，本轮只增加逻辑分类说明。

## 后续迁移门槛

测试文件的物理分目录、真实 Adapter 目录、examples、Host 或 Extended 目录需要独立任务。每次只能在源集、调用树、任务表、操作记录与知识库同步后迁移，且必须重新执行多 Profile 构建。
