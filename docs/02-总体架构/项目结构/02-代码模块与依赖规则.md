# 代码模块与依赖规则

| 模块 | 目录 | 负责内容 | 禁止内容 |
| --- | --- | --- | --- |
| core | src/core | 配置校验、Frame、Endpoint、纯定点 LC-1 Cost Resolver、内部基础工具。 | RTOS、驱动、路由策略、业务。 |
| node | src/node | Node、邻居、HELLO、Heartbeat、收发调度、Nano/Profile 差异。 | SDK、硬件引脚、任务创建。 |
| transport | src/transport | Adapter RX Queue、Link 边界、Protocol Owner、静态 Preset、SDK 无关多 Source Event Runtime。 | 具体 Bearer 驱动、Driver Ring、路由策略。 |
| adapters/stream | src/adapters/stream | 调用者存储的 Stream Byte Ring、COBS+0 Carrier、Event Runtime Source。 | UART/USB SDK、GPIO、DMA Handle、RTOS 对象、CAN 分段。 |
| adapters/can | src/adapters/can | 调用者存储的 CAN Frame Ring、CAN-FD DLC 补齐、经典 CAN Carrier/重组、Bus State。 | CAN SDK、寄存器、收发器/引脚、自动硬件恢复、Stream COBS。 |
| routing | src/routing | Path、Policy、主备、流亲和均衡。 | ISR、驱动、业务任务。 |
| service | src/service | Router、Inbox、Remote TX、Protocol Bridge。 | 多任务直接访问 Node、动态队列。 |
| ports | src/ports | Bare-metal、FreeRTOS、Zephyr、NuttX、RT-Thread、Host Fake 的独立运行外壳。 | 其它 RTOS 头、Bearer 驱动、Node 内部字段。 |
| extended | src/extended | 按需链接的 Transfer Class、有界分片/重组、ACK/重试和固定 RX Handle。 | 动态内存、无限消息、在中继重组、侵占 Core Q0。 |

允许方向为：ports 和产品 Adapter 使用 transport；transport、routing、service、extended 通过公开契约使用 node/core。反向依赖一律禁止。若某个功能既需要 Bearer SDK 又需要 Node，只能在产品 Adapter/Bridge 层组合，不能让 core 引入 SDK。

公开头保留在 include/ucn 顶层，以避免现有产品的 include 路径变化；只有已经独立的 Platform Port 使用 include/ucn/ports 子目录。

`ucn_event_runtime.c` 属于 transport 并进入 `ucn_core`：它只管理固定 Source、事件位、预算和公共 Owner，不知道某个 Source 是 UART、CAN、USB 还是 Wi-Fi。`adapters/stream` 供 UART/RS-485/USB CDC 复用 COBS 状态机；`adapters/can` 供 CAN-FD/经典 CAN 复用 Frame Ring 与独立 Carrier。具体 BSP 仍在产品边界。RTOS 文件只映射 `notify_owner/wait_owner/yield_owner`，禁止为每种 RTOS 再复制 Carrier 状态机。

V5-62 的公共工程契约是 Port API V2：所有 transport/adapter/port 使用同一 `ucn_port_ops_t` 大小与版本，任何短结构或旧版本在初始化时失败关闭。Transfer 只从配置回调读取权威单调时间；CAN Source 必须先提交完成 Carrier 才消费下一物理帧。这些规则允许预发布源码/ABI 破坏，但不改变 Wire。
