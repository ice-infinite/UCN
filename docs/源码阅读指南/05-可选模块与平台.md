# 可选模块与平台阅读顺序

## Realtime

读 `ucn_v6_realtime.h/.c`：Envelope codec → uncertainty aggregate → owner init → policy/domain →
sample ingest → clock → prepare payload → receive/execution admit。审计 unknown 分量、半开 Deadline、
同代际单调高水位、HOLDOVER 和失锁清理。

## Cluster

读 `ucn_v6_cluster.h/.c`：Record codec/store → create/member → backup → Joint → takeover → handover
→ recovery/rekey → directory/tunnel → step/preflight。审计 persist-before-promise、VoteId、双 quorum、
不可逆 Fence、跨 Cluster Term 和 restart。

## Adapter

读 `ucn_v6_adapter.h/.c` 的 RX/TX token 状态机，再看 adapters 下 UART/Wi-Fi/CAN/USB 配置，
随后读 FreeRTOS Port 和 ESP32-S3 reference。审计一个 token 是否只能 RESERVED→SUBMITTED→
COMPLETED/CANCELLED，Driver 失败时 obligation 是否仍可重试，跨 Link callback gate 是否安全。

Feature 关闭后 CMake 不构建对应 archive，umbrella 不包含对应头。边界脚本同时检查 Realtime
与 Cluster 无相互依赖、旧源码和旧 Option 不会重新进入发布树。
