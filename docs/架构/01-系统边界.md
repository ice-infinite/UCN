# 系统边界

## 三个不混淆的概念

| 概念 | 说明 | 不是 |
| --- | --- | --- |
| UCN-Core | MCU 上的 Frame、Node、邻居、路由、Q0/Q1、固定表与安全 Provider 边界。 | Linux 服务、SDK 驱动或业务执行器。 |
| Product Port + Adapter | 产品提供的时钟、临界区、RTOS 通知、UART/WiFi/CAN/USB 字节收发和指标采集。 | Core 的路由所有者或网络中心。 |
| UCN-Host | 后续将 Linux、ROS2、MAVLink、日志或运维受控接入的可选模块。 | MCU 网络的必经节点。 |

Nano/Lite/Full 是同一个 Core 在不同节点上的编译档案；Service ON/OFF 是正交开关。它们不等于目录，也不等于节点在网络中的角色。

## 运行链

    介质驱动 ISR/回调
      -> BSP 固定 ring（推荐）或所选 Platform Port 的 ISR token 入队
      -> Transport RX Queue
      -> 唯一 Protocol Owner
      -> Node / Routing / Service Bridge
      -> Link send

一个 Node 只有一个 Protocol Owner。业务任务、日志任务与 ISR 均不能直接并发进入 Node。

若 ISR 直接把完整帧交给 Adapter RX Queue，产品必须提供独立的
`enter_critical_from_isr()` / `exit_critical_from_isr(token)`；缺失时入口
返回 `UCN_ERR_CONFIG`，绝不把 ISR 当成普通任务使用任务临界区。这个
token 用于恢复 ISR 进入前的中断掩码，适配 FreeRTOS 等不同 Task/ISR
临界区 API；它不证明真实 SDK/BSP 的嵌套中断时序已经验证。

## 未实现边界

真实 UART、ESP-NOW/WiFi、CAN-FD、USB CDC、经典 CAN Carrier、生产 Host、Extended Gateway 和生产安全 Provider 不因存在接口或目录而视为完成。
