# 构建目标与测试地图

| Target | 作用 | 产品是否默认链接 |
| --- | --- | --- |
| ucn_core | MCU-first 通用协议 Core；没有具体 RTOS Port。 | 是。 |
| ucn_port_bare_metal | Super Loop Port。 | 仅裸机产品。 |
| ucn_port_freertos | FreeRTOS Protocol Task Port。 | 仅 FreeRTOS 产品。 |
| ucn_port_zephyr / nuttx / rtthread | 对应系统的独立 Port。 | 只选择一个。 |
| ucn_port_host_fake | Host 单元测试 Port。 | 否。 |
| ucn_tests | 单元、模块与虚拟集成测试超集。 | 否。 |
| ucn_scale_sim | Host-only 大规模模拟器。 | 否。 |

`ucn_scale_sim --topology auto` 是 CTest 的常规 Smoke：`UCN_MAX_LINKS>=4`
选三叉 tree，`2..3` 选 line；低容量产品不会因不可能的 tree 被误判失败。
`ucn_scale_tree_capacity_contract` 单独输出 tree 的 `SUPPORTED` 或
`CAPACITY_SKIPPED`，因此“常规 Smoke 通过”不等于该产品跑过 tree。

测试物理路径暂时兼容既有 tests 根目录，但逻辑分类如下：

| 类别 | 代表文件 |
| --- | --- |
| Core Codec | test_core、test_frame、test_wire_profile、test_endpoint、test_time、test_link_cost。 |
| Node/Neighbor | test_node、test_hello_join、test_neighbor_*、test_aodv_lite。 |
| Transport/Port | test_adapter、test_standard_adapter、test_protocol_owner、test_link_contract；含 Task/ISR token 锁分流、缺 ISR 锁失败关闭和六个 Port 的 Host Fake 路径。 |
| Routing | test_route、test_candidate_route、test_neighbor_bearer、test_path_*、test_policy*；覆盖 LC-1 的 Bearer/Candidate/Q1 接入。 |
| Service | test_service、test_service_bridge。 |
| Integration/Stress | test_virtual_link、test_integration、test_stress、test_dynamic_stress。 |
| Profile/Config | test_profile、test_public_headers、test_config_contract、tests/config。 |

测试本身不等于实机验证。真实 Bearer、RTOS 调度、Flash/RAM/栈、吞吐和功耗仍须在产品工程单独记录。
