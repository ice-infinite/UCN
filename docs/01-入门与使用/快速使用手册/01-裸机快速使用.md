# UCN 裸机快速使用

> `ARCHIVED / NOT CURRENT`：本文仅保留 v5 裸机接入记录；v6 请从[当前用户手册](../../用户手册/README.md)开始。

> 适用：没有 RTOS 的 Super Loop、单主循环裸机项目。目标是用最少的对象完成一条 UART、CAN、ESP-NOW 等 Link 的收发；不在 ISR 内运行 UCN Core。

> 当前 API：V5-62 Port API V2 要求所有 `ucn_port_ops_t` 具名填写 `struct_size/api_version`；旧位置初始化与旧对象不兼容。Transfer 还必须配置权威时钟并使用无时间参数的 `ucn_transfer_step()`。迁移见[总览](README.md)。

## 1. 资源与构建

按[总览的 Profile 源文件矩阵](README.md#共同的构建输入)选择 C99 源文件，包含目录设为仓库 `include/`，并让所有编译单元使用一致的 `UCN_PROFILE`、`UCN_FEATURE_SERVICE` 和产品配置头。所有 UCN 对象放在静态区：

```c
#include "ucn/ucn.h"
#include "ucn/ucn_adapter.h"
#include "ucn/ucn_node_storage.h"

static ucn_node_t g_node;
static ucn_link_t g_link;
static ucn_adapter_rx_queue_t g_rx_queue;
```

如果收包只在主循环轮询，调用 `ucn_adapter_rx_queue_init(&g_rx_queue, NULL, NULL)` 即可。若任务/主循环会并发访问该队列，`ucn_port_ops_t` 必须填入成对的 `enter_critical/exit_critical`。若完整帧由 ISR 直接进入 Queue，则还必须填入 `enter_critical_from_isr/exit_critical_from_isr(token)`，并从 ISR 调用 `ucn_adapter_rx_enqueue_from_isr()`；缺这一对时会返回 `UCN_ERR_CONFIG`，不能用任务锁替代。更小、可审计的裸机方案仍是 ISR 写 DMA/ring，主循环普通入队。

## 2. 初始化 Node 与 Link

`node_id` 是稳定设备身份，不是入网临时地址。下例只展示 Core 调用；`g_board_link_ops` 由板级 Adapter 实现。

```c
static void ucn_start(void)
{
    /* 产品应从持久启动计数或受控随机源取得；本例 W1 要求 1..0xFFFF。 */
    const ucn_session_id_t boot_session = board_next_boot_session_id();
    const ucn_config_t config = {
        .network_id = UINT32_C(0x00004E01), /* 必须能被 W1 表达。 */
        .node_id = UINT32_C(0x0000000A),
        .default_hop_limit = 8U,
    };

    g_link = (ucn_link_t){
        .ops = &g_board_link_ops,
        .context = &g_board_link_context,
        .link_id = 1U,
        .mtu = UCN_MAX_FRAME_BYTES,
        .peer_node_id = 0U, /* 发现型 Adapter 可先未知。 */
    };

    if (ucn_node_init(&g_node, &config) != UCN_OK ||
        ucn_node_set_wire_profiles(&g_node,
            UCN_WIRE_PROFILE_W1_EDGE,
            UCN_WIRE_PROFILE_W3_BACKBONE) != UCN_OK ||
        ucn_node_set_wire_profile_auto(&g_node, true) != UCN_OK ||
        ucn_node_set_plain_session_id(&g_node, boot_session) != UCN_OK ||
        ucn_adapter_rx_queue_init(&g_rx_queue, NULL, NULL) != UCN_OK ||
        ucn_node_register_link(&g_node, &g_link) != UCN_OK) {
        board_enter_safe_mode();
    }
}
```

`ucn_node_set_wire_profiles()` 必须位于 Link 注册和 Security 安装之前。一般产品采用“最低够用 TX/W3 RX”：小节点可用 W0/W3，常规 MCU Mesh 可用 W1/W3；这样不会扩大自己的小包，同时能接收高档节点下发的普通 Endpoint 指令。W1 的 Network/Session 最大值为 `0xFFFF`、Node ID 最大值为 `0xFFFE`、Hop 上限为 16；任何固定字段越界都会返回 `UCN_ERR_TOO_LARGE`，不会截断。只有 MTU、资源或安全域明确受限时才使用 W0/W0。

本例是明文开发启动，所以显式设置非零 Boot Session；该值在接收端重复窗口仍有效期间不能跨重启复用。生产安全节点改为安装 Security Provider，并让 Provider 提供认证 Session/Sequence 持久状态。`ucn_node_register_link()` 会调用非空的 `link.ops->open()`，不要在注册前再次手动 `open()`。

编译期表深、队列、MTU 和超时统一从 `ucn_config.h` 进入。产品推荐提供独立 `UCN_USER_CONFIG_HEADER`，未覆盖项继续使用默认值；详细优先级见[全局公共配置说明](../UCN_全局公共配置说明.md)。

`send()` 只接受 Core 已编码的完整帧：可以立即发送，也可以提交到**有界**的硬件 TX 队列。`get_status()` 必须如实报告 Link Down；`get_metrics()` 将 RSSI、重传、错误率或队列压力归一为数值越小越好的 `route_cost`。不要在 Adapter 改写 UCN 的源、目的、TTL、序号或 Path ID。

若 Carrier MTU 会在运行期改变，可把 `g_link.mtu` 设为 0，并由 `get_status().mtu` 报告当前完整 UCN 帧上限；若还配置了静态 MTU，则实际取两者较小值。当前值为 0 时该 Link 暂不参与发送，恢复后无需注销/重新注册。窄 Link 还可在注册前调用 `ucn_node_set_link_local_wire_profile_limit()` 收窄本地接收档。

## 3. 让接收路径不阻塞中断

推荐使用 DMA/中断收集原始数据。UART、RS-485、USB CDC 可直接初始化 `ucn_stream_source_t`，ISR/主循环分别调用 `ucn_stream_source_write_from_isr()` / `ucn_stream_source_write()`；公共 Source 会在 Owner 主循环中用 COBS+0 解出完整 UCN 帧。其他 Carrier 才需要产品先解出完整帧后再调用下列函数。

```c
static void board_rx_poll(void)
{
    uint8_t frame[UCN_MAX_FRAME_BYTES];
    size_t length;

    while (board_link_take_complete_frame(frame, sizeof(frame), &length)) {
        const ucn_result_t rc =
            ucn_adapter_rx_enqueue(&g_rx_queue, &g_link, frame, length);
        if (rc != UCN_OK) {
            board_count_rx_drop(rc); /* 满队列必须丢弃并计数。 */
        }
    }
}
```

硬中断只负责 DMA 索引、环形缓冲或 PendSV/软件中断通知。不要直接从硬中断调用 `ucn_adapter_rx_enqueue()` 后再 Pump，更不能调用 `ucn_node_receive()`。

## 4. 主循环就是唯一 Protocol Task

```c
static void application_loop(void)
{
    size_t pumped = 0U;
    const uint32_t now_ms = board_monotonic_ms();

    board_rx_poll();
    (void)ucn_adapter_rx_pump(&g_rx_queue, &g_node, 4U, &pumped);
    (void)ucn_node_step(&g_node, now_ms);

    application_sensor_tick();
    application_control_tick();
}
```

如需动态发现，在受控低频节拍调用 `ucn_node_broadcast_hello(&g_node, &g_link, now_ms)` 或 `ucn_node_probe_neighbor(&g_node, &g_link, now_ms)`；不要为每个业务包广播 HELLO。Q1 Endpoint 在未知多跳目的地时可开始受限寻路；Q0 不等待未知路由，调用者要立即进入本地安全策略。

## 5. 最小 Endpoint 收发

```c
static void on_imu(void *context, const ucn_frame_t *frame)
{
    (void)context;
    if (frame->payload_length == 24U) {
        application_store_imu(frame->payload);
    }
}

void application_ucn_init(void)
{
    (void)ucn_node_set_endpoint_handler(&g_node, 0x40U, on_imu, NULL);
}

void application_publish_imu(const uint8_t payload[24])
{
    const ucn_result_t rc = ucn_node_send_endpoint(
        &g_node, UINT32_C(0x0000000B), 0x40U,
        UCN_TRAFFIC_Q1_REALTIME, payload, 24U);
    if (rc != UCN_OK) {
        board_count_tx_error(rc);
    }
}
```

Endpoint handler 也运行在主循环上下文，应只复制/更新有限状态，不能等待、做长耗时 IO 或再次并发访问 Node。

## 6. 上板前检查

- 两块板 `network_id` 一致、`node_id` 不重复，Endpoint 的长度/字节序/QoS 一致。
- 先观测 Adapter `dropped_full`、`rejected_by_core` 和 Node `tx/rx` 统计，再增加发送频率。
- Q0 的执行器在没有新命令或出现 `UCN_ERR_LINK_DOWN` 时进入本地安全状态；不要等待重传无限堆积。
- 需要多个本机并行业务时，转到 [通用 RTOS](02-通用RTOS快速使用.md) 的 Service Router 模型，而不是从多个中断或循环并发调用 Node。

## 7. S16 主循环时限

产品必须显式设置 `UCN_MAX_STEP_INTERVAL_MS`（默认 10 ms），并保证主循环最坏路径仍能按时再次调用 `ucn_node_step()`。每轮 RX Pump 和 Bridge 数量必须固定；轮询驱动 `send()` 不能无界等待。启动后周期读取 `max_step_gap_ms` 与 `step_interval_violations`，任何非零违规都要进入产品诊断；默认资源档案的保守维护服务上界是 800 ms。

## 8. V5-58 多外设事件接入

同时使用 UART/CAN/USB/无线时，静态创建一个 `ucn_event_runtime_t`，每个外设实例绑定一个 Source。裸机配置 `scheduler_ops=NULL`；ISR 只写各自 Ring 并调用 `ucn_event_runtime_signal_source_from_isr()`，主循环先检查 `ucn_event_runtime_has_pending()`，有事件立即 `run(false)`，周期保底执行 `run(true)`。只有主循环执行 Source `service()`、Carrier 解帧和 Node；WFI/SEV 是否使用由 BSP 决定。
