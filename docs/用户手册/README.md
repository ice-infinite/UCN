# UCN v6 用户手册

本手册面向把 UCN 集成到产品的人，只说明如何配置、初始化、发送、接收、接驱动和验收。
不要求先理解私有状态机。精确声明以 `include/ucn/v6/` 为准。

建议顺序：

1. [五分钟快速开始](00-五分钟快速开始.md)
2. [配置、Profile 与对象初始化](01-配置、Profile与对象初始化.md)
3. [发送消息与可靠 Transfer](02-发送消息与可靠Transfer.md)
4. [接入 UART、CAN、Wi-Fi 与 USB](03-接入UART、CAN、Wi-Fi与USB.md)
5. [启用 Realtime 与 Cluster](04-启用Realtime与Cluster.md)
6. [故障诊断与产品验收](05-故障诊断与产品验收.md)

当前手册只适用于 v6。旧 v5 手册已归档，不要复制旧初始化代码到当前产品。
