# CLV2-14-08 实机门禁阻断记录

## 结论

`CLV2-14-08` 当前为 **BLOCKED / REAL HARDWARE REQUIRED**。这不是软件失败，也不是可用模拟测试替代的项目；它是 M14 发布前必须保留的真实设备门禁。

## 当前缺失条件

- 至少 4 块可重复烧录、可唯一识别的 MCU 板；
- 一跳 Backup 覆盖拓扑及 UART/CAN/ESP-NOW 等 Bearer 的确定接线；
- 真实 Flash Persistence Provider 与可控制的断电/复电手段；
- 四路同步串口或等价的原始事件采集；
- 每个固件的构建参数、Git commit、SHA256 与烧录记录。

## 必测矩阵

1. 稳态入网、成员与 Backup 覆盖；
2. Primary 故障、Backup 故障与链路抖动；
3. 同步、异步和多轮 Pending Persistence；
4. Prepare/Commit 各写入窗口的掉电与双槽恢复；
5. Wire v4 40 B 跨 Bearer 传输、拒绝和 replay；
6. UART、CAN、ESP-NOW 单独及混合路径；
7. 每组至少重复 10 轮，并保留失败轮的完整原始日志。

## 放行证据

只有同时具备拓扑图、引脚表、设备 Node ID、固件 Hash、原始日志、掉电时刻、介质内容与重复统计，才能把 14-08 从 BLOCKED 改为 DONE。Host CTest、ASan、规模模拟和 fake Provider 均不能替代上述证据。

## 当前影响

- 阻断 `CLV2-14-11` 的最终生产级签字；
- 阻断 `CLV2-14-12` release tag；
- 不阻止继续完成资源、文档和软件范围安全自审。
