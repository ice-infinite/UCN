# CLV2-05-11 版本与能力诊断自审报告（2026-08-22）

## 结论

`CLV2-05-11` 已获 **DONE / 外部复审 GO（受限范围）**。本项只提供 isolated v4 codec 的 caller-owned diagnostic view / reason / stats；没有接入生产 v4 RX/TX/FSM、Member/资格、Authority 或 v4 发送。M05 整体继续 `AUDIT HOLD`。

## 实现核对

| 项目 | 结果 |
|---|---|
| 诊断输入与 view | private `ucn_cluster_wire_v4_peer_diagnostic_input_t` / `view_t` 固定记录 peer Node ID、v3/v4 format、offer presence/内容、policy、请求类别、required bits、compatibility result 和 reason。它们不嵌入 `ucn_cluster_t`。 |
| 原有策略唯一性 | `ucn_cluster_wire_v4_diagnose_peer()` 复用 `ucn_cluster_wire_v4_mixed_version_peer_is_compatible()`；未复制或改变 05-08 的兼容性语义。 |
| v3 合同 | Strict v4 明确给出 `STRICT_V4_REQUIRES_V4`；legacy 下 Voter/Backup/Head 给出 `V3_LEGACY_NON_VOTING_ONLY`；唯一合法 legacy 是 non-voting。v3 携带 offer 或 required v4 bit 仍为 `UCN_ERR_ARGUMENT`，不被诊断层错误降格。 |
| v4 合同 | 缺 offer、非法 offer、缺 required capability 分别给出稳定 reason；覆盖要求时仅输出 `COMPATIBLE_V4`，绝不代表已获真实资格。 |
| 失败无副作用 | 非法 input 返回 `UCN_ERR_ARGUMENT` 且 `view` 保持逐字节不变；兼容性拒绝以 `view.compatibility = UCN_ERR_STATE` + reason 输出，不修改 Cluster。 |
| 统计 | `ucn_cluster_wire_v4_peer_diagnostic_stats_t` 为调用方持有、5 个 `uint32_t` 计数器；只有显式 record 才累积，使用饱和递增，`INPUT_INVALID` 单独计数。没有在 MCU 常驻对象中增加 RAM。 |

## 定向覆盖

- Strict v4 拒绝 v3；显式 legacy 对 Backup 拒绝、对 non-voting 通过；
- v4 的 missing / invalid / capability-insufficient / capability-sufficient offer；
- 全部 reason 的 stats 分桶、统计饱和；
- 无效 peer ID、format、v3+offer、v3+required-bits 均保持 output 不写回；
- 05-08 的原 helper 回归仍保持；本项没有新增/启用任何 encoder 或生产处理路径。

## 自审发现与修正

首次编译暴露了 C 标识符在换行处被错误拆分；修复后才执行上述重新构建和全部回归。随后合同复核发现：若将 `v3 + required v4 capability` 作为普通 reason，会与 05-08 已冻结的 `UCN_ERR_ARGUMENT` 语义冲突。已修正为保持原参数错误、view 不写回，调用方只可记录 `INPUT_INVALID`；因此没有发生兼容策略漂移。

## 仍然禁止的事项

- 不得把 `COMPATIBLE_*` 作为 Join、Member、Voter、Backup、Head、Takeover 或 Authority 的授权。
- 不得把 diagnostic view/stats 塞入当前 `ucn_cluster_view_t`、`ucn_cluster_stats_t` 或 `ucn_cluster_t`；真实 peer 生命周期和可观测状态归 M06 后的 v4 RX Owner。
- 不得因 Host/ASan/analyzer 绿灯宣称实机日志、真实双栈互通或 M05 完成。

外部复审已确认：诊断严格复用 05-08 的兼容性判断，v3 伪造 offer 或 required v4 bit 仍为 `UCN_ERR_ARGUMENT`；拒绝 view、无写回和显式饱和 stats 均符合合同。外审独立复跑 Windows Full `2/2`、WSL ASan/UBSan `25/25`，并确认没有 production v4 引用。现在可开始**受限** 05-12；M05 `AUDIT HOLD` 继续有效，不能据此接入真实角色、Authority 或生产路径。
