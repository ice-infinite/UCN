# 性能、资源、长稳与功耗验收

> 文档级别：`NORMATIVE`
> 实现状态：`CURRENT（测试规范）`
> 适用版本：UCN 5.0.0 / Core Wire v5
> 事实源：CMake、tests、tools、results 与审计门禁
> 最近核对：`codex/v5-adaptive-wire@a093862`，2026-08-25
> 硬件状态：实机证据按具体报告；规范本身不代表已验收

按 payload class、hop、窗口和 Bearer 测 goodput、RTT、p50/p95/p99、重传、丢包、队列峰值和 CPU。资源记录 RAM/Flash/stack/heap high-water；功耗记录空闲、控制面、持续业务和故障恢复。

长稳至少分 1h/8h/24h，期间注入断链、节点重启和流量突发。结果按阶段统计，不能只用总平均掩盖长尾或短暂断网。

## 性能层级

分别测Driver raw、Carrier完整帧、Core单帧、Route中继、Transfer和业务Task。每层使用同一payload pattern，才能定位损耗。吞吐用有效payload/s，RTT注明应用echo或协议ACK。

## 延迟

记录p50/p95/p99/max和deadline miss，不只平均。Q0控制在同时运行Q1/Transfer/Cluster时测；若时钟不同，使用往返或同步误差范围，不能直接相减两个MCU uptime。

## 资源

- Flash：最终map的text/rodata/data和各archive贡献；
- RAM：`.data/.bss`、对象实例、Driver/RTOS buffer；
- Stack：每任务high-water、ISR stack、静态frame；
- Heap：启动/稳态/峰值minimum free，区分SDK和UCN；
- CPU：Owner、Driver callback、加密、总负载及p99执行时间。

报告绑定Profile/容量/优化级别。Host sizeof仅做趋势。

## 长稳阶段

| 阶段 | 动作 |
| --- | --- |
| 基线 | 稳定流量，无故障 |
| 突发 | 周期性满队列/大Transfer |
| 单断链 | 每种Bearer断开/恢复 |
| 节点重启 | Member/relay/Head分别重启 |
| 分区 | 多段断开后合并 |
| 安全/存储 | session轮换/受控Provider失败 |

每阶段单独统计错误增量和恢复时间。8h中发生一次5s断网不能被总平均吞吐隐藏。

## 功耗

测空闲离网、已入网无业务、Heartbeat/Cluster控制、持续小包、大Transfer、加密和故障恢复。记录电压、采样设备/频率、平均/峰值和无线发射配置。USB供电电流不能准确代表电池域时要说明。

## 通过标准

由产品预先定义goodput、p99、丢包、CPU、stack/RAM余量、功耗和恢复时间阈值。测试后临时修改阈值使结果通过不可接受。
