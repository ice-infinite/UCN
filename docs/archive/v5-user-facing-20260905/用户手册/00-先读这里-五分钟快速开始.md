# 先读这里：五分钟快速开始

本篇先完成最小闭环：两个节点通过一条已知 Link 发送 Endpoint 消息。这里不启用自动组网、Transfer、安全或 Cluster，便于先证明产品 Driver 与 Core 的基本边界正确。

## 1. 构建库

第一次建议使用 Full，功能最多、排查接口最全：

```powershell
cmake -S . -B build_user_full `
  -DUCN_PROFILE=FULL `
  -DUCN_FEATURE_SERVICE=ON `
  -DUCN_BUILD_TESTS=ON
cmake --build build_user_full --config Debug
ctest --test-dir build_user_full -C Debug --output-on-failure
```

产品通过 CMake 链接：

```cmake
add_subdirectory(path/to/UCN)
target_link_libraries(my_firmware PRIVATE ucn_core)
```

如果需要大消息，再额外链接 `ucn_transfer`；普通小消息不需要它。

## 2. 为产品冻结三个编号

示例约定：

```c
#define PRODUCT_NETWORK_ID UINT32_C(0x12345678)
#define NODE_A_ID          UINT32_C(1)
#define NODE_B_ID          UINT32_C(2)
#define ENDPOINT_IMU       ((ucn_endpoint_t)0x40U)
```

- 同一网络内 `network_id` 必须一致；
- `node_id` 必须非 0、非广播值并且网络内唯一；
- 业务 Endpoint 使用 `0x40..0xBF`；
- Endpoint 编号、Payload 格式、字节序、单位和版本必须写入产品 ABI 文档。

## 3. 准备静态对象

只有真正拥有 Node 的翻译单元包含 storage 头：

```c
#include <string.h>

#include "ucn/ucn.h"
#include "ucn/ucn_endpoint.h"
#include "ucn/ucn_link.h"
#include "ucn/ucn_node_storage.h"

static ucn_node_t g_node;
static ucn_link_t g_link;
```

其他业务文件只保存指针并包含 `ucn_node.h`，不要读取 `ucn_node_t` 内部字段。

## 4. 实现产品 Link 回调

下面是接口形状，不包含具体厂商 SDK：

```c
static ucn_result_t product_link_send(
    ucn_link_t *link,
    const uint8_t *frame,
    size_t length)
{
    product_driver_t *driver = (product_driver_t *)link->context;

    if (!product_driver_is_up(driver)) {
        return UCN_ERR_LINK_DOWN;
    }
    if (!product_driver_tx_enqueue_copy(driver, frame, length)) {
        return UCN_ERR_NO_SPACE;
    }
    return UCN_OK;
}

static ucn_result_t product_link_get_status(
    const ucn_link_t *link,
    ucn_link_status_t *status)
{
    product_driver_t *driver = (product_driver_t *)link->context;

    status->is_up = product_driver_is_up(driver);
    status->mtu = product_driver_current_mtu(driver);
    status->tx_errors = product_driver_tx_errors(driver);
    status->rx_errors = product_driver_rx_errors(driver);
    return UCN_OK;
}

static const ucn_link_ops_t PRODUCT_LINK_OPS = {
    .open = NULL,
    .send = product_link_send,
    .poll_rx = NULL,
    .get_status = product_link_get_status,
    .close = NULL,
    .get_metrics = NULL
};
```

`send()` 的重要合同：

- 必须复制或立即消费输入 Frame；返回后不能继续保存这个临时指针；
- 只做有界入队，不等待 UART 全部发完或无线 ACK；
- 队列满返回 `UCN_ERR_NO_SPACE`；
- 介质不可用返回 `UCN_ERR_LINK_DOWN`。

## 5. 初始化 Node 和 Link

```c
static ucn_result_t product_ucn_init(
    product_driver_t *driver,
    ucn_node_id_t local_id,
    ucn_node_id_t peer_id,
    ucn_session_id_t boot_session)
{
    const ucn_config_t config = {
        .network_id = PRODUCT_NETWORK_ID,
        .node_id = local_id,
        .default_hop_limit = 4U
    };
    ucn_result_t result;

    (void)memset(&g_node, 0, sizeof(g_node));
    (void)memset(&g_link, 0, sizeof(g_link));

    result = ucn_node_init(&g_node, &config);
    if (result != UCN_OK) {
        return result;
    }
    result = ucn_node_set_wire_profiles(
        &g_node,
        UCN_WIRE_PROFILE_W0_LOCAL,
        UCN_WIRE_PROFILE_W3_BACKBONE);
    if (result != UCN_OK) {
        return result;
    }
    result = ucn_node_set_plain_session_id(&g_node, boot_session);
    if (result != UCN_OK) {
        return result;
    }

    g_link.ops = &PRODUCT_LINK_OPS;
    g_link.context = driver;
    g_link.link_id = 1U;
    g_link.mtu = UCN_MAX_FRAME_BYTES;
    g_link.peer_node_id = peer_id;

    result = ucn_node_register_link(&g_node, &g_link);
    if (result != UCN_OK) {
        return result;
    }
    return ucn_node_add_route(&g_node, peer_id, &g_link);
}
```

`boot_session` 每次启动必须使用新的非零值。正式安全产品应由 Security Provider 管理认证 Session，而不是自行使用普通 Session。

## 6. 注册接收 Endpoint

```c
typedef struct imu_sample_wire {
    uint32_t sample_id_be;
    int16_t accel_x_be;
    int16_t accel_y_be;
    int16_t accel_z_be;
} imu_sample_wire_t;

static void on_imu(void *context, const ucn_frame_t *frame)
{
    imu_consumer_t *consumer = (imu_consumer_t *)context;

    if (frame->payload_length != sizeof(imu_sample_wire_t)) {
        consumer->bad_length++;
        return;
    }
    imu_consumer_accept_copy(consumer, frame->source,
                             frame->payload, frame->payload_length);
}

ucn_result_t register_handlers(imu_consumer_t *consumer)
{
    return ucn_node_set_endpoint_handler(
        &g_node, ENDPOINT_IMU, on_imu, consumer);
}
```

回调里的 `frame` 和 `payload` 只在回调期间有效。任务以后再处理的数据必须在回调内复制到自己的固定队列。

## 7. 发送一条消息

```c
ucn_result_t send_imu(
    ucn_node_id_t destination,
    const imu_sample_wire_t *sample)
{
    return ucn_node_send_endpoint(
        &g_node,
        destination,
        ENDPOINT_IMU,
        UCN_TRAFFIC_Q1_REALTIME,
        (const uint8_t *)sample,
        (uint16_t)sizeof(*sample));
}
```

返回值解释：

| 返回值 | 当前层含义 | 应用动作 |
| --- | --- | --- |
| `UCN_OK` | Frame 已被当前发送路径接受 | 不等于远端任务已执行 |
| `UCN_ERR_NOT_FOUND` | 没有可用 Route/Path | Lite/Full 发起发现，Nano检查静态 Route |
| `UCN_ERR_NO_SPACE` | 本地队列或 Adapter 满 | 按业务策略丢旧、稍后重试或告警 |
| `UCN_ERR_LINK_DOWN` | 选中的 Link 不可用 | 触发故障处理或让策略选择其他路 |
| `UCN_ERR_TOO_LARGE` | Frame/MTU 放不下 | 减小 Payload 或使用 Transfer |
| `UCN_ERR_SECURITY` | 安全要求未满足 | 不得降级明文，修复 Provider/Policy |

## 8. 持续推进协议

最小裸机循环：

```c
for (;;) {
    uint32_t now_ms = product_monotonic_ms();
    ucn_result_t result;

    product_drain_complete_frames_to_node(&g_node, &g_link);
    result = ucn_node_step(&g_node, now_ms);
    if (result != UCN_OK && result != UCN_ERR_NOT_FOUND) {
        product_record_ucn_error(result);
    }
    product_wait_until_event_or_deadline();
}
```

真实产品优先使用 Event Runtime/Protocol Owner；Driver ISR 不直接调用 `ucn_node_receive()` 或业务回调。

## 9. 最小验收清单

- 两端 Network ID 一致、Node ID 不同；
- 两端 Endpoint ABI 完全相同；
- Link `send()` 会复制数据，不保存临时指针；
- RX 数据最终在唯一 Owner 上下文进入 Node；
- 每次启动 Session 不复用；
- `step()` 的时间单调且调用间隔有上限；
- 分别验证正常发送、Link Down、队列满和错误长度；
- 关闭串口日志后重新验证吞吐和丢包。
