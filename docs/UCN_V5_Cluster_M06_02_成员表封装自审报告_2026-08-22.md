## 2. 低资源修正

初版模型测试曾使用固定 `slots[3]` / `slots[7]`。这会使小容量产品配置存在测试越界风险，故在自审中立即改为只使用 `slots[0]` 和独立 invalid-table 副本。带 `UCN_USER_CONFIG_HEADER=ucn_test_user_config.h`、`UCN_CLUSTER_MAX_MEMBERS=6` 的产品配置已重新构建并通过，测试不再假设成员表的最小槽数大于 1。
