# UCN 文档中心

当前协议只有 v6 一个实现入口。读者应从[官方文档](official/README.md)或
[用户手册](用户手册/README.md)开始；`00-项目管理`、`08-实现与验证` 和
`10-理论与规划` 用于追溯任务、证据与设计依据，不替代当前公共头。

## 当前资料

- `official/`：与当前 v6 源码同步的规范性说明；
- `用户手册/`：只讲产品如何配置、调用、驱动和验收；
- `源码阅读指南/`：面向开发与人工审计的代码阅读路线；
- `00-项目管理/`：任务状态、操作记录、Compatibility Removal Manifest；
- `08-实现与验证/`：阶段实现与验证报告；
- `evidence/`、`results/`：证据索引和生成结果。

## 历史资料

规划阶段。它们可解释为何作出某项设计，但不代表当前 API、Wire、配置或成熟度。
原 v5 官方文档、用户手册、阅读指南与调用树已整体归档到
[`archive/v5-user-facing-20260905/`](archive/v5-user-facing-20260905/README.md)。

发生冲突时按以下顺序裁决：当前公共头与实现、当前 CMake/测试、`official/`、绑定提交的
验证报告、任务与操作记录、历史材料。
