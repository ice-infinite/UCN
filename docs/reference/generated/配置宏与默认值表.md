# 配置宏与默认值表

| 类别 | 代表宏 | 默认/说明 |
| --- | --- | --- |
| Wire | `UCN_MAX_FRAME_BYTES` | 256 B |
| Hop | `UCN_MAX_HOPS` | 16 |
| Owner | `UCN_MAX_STEP_INTERVAL_MS` | 10 ms |
| Link/Route | `UCN_MAX_LINKS` / `UCN_MAX_ROUTES` | 4 / 8 |
| Neighbor | `UCN_MAX_NEIGHBORS` | 8 |
| Endpoint | `UCN_MAX_ENDPOINT_HANDLERS` | 8 |
| Heartbeat | `UCN_HEARTBEAT_INTERVAL_MS` | 1000 ms |
| Transfer | ACK/RX timeout | 250 / 5000 ms |
| Cluster | Advertise/Keepalive | 1000 / 2000 ms |

完整值以 `include/ucn/ucn_config.h` 为准。产品覆盖顺序见[全局配置说明](../../official/08-配置与资源/01-全局配置、回退值与覆盖优先级.md)。
