## 1. 外审问题与确认

| 项 | 原因 | 确认 |
|---|---|---|
| R31 / P0 | `authority_active` 只在旧 `ucn_cluster_step()` 刷新；RX、Cluster TX 和 Federation 可读取过期缓存。 | 属实。过期 voter lease 后，先调用其它入口时缺少当前时刻的 Owner 评估。 |
| R32 / P0 | `install_config()` 仅替换 Config 和 phase，未撤销旧 `authority_active`。 | 属实。切到缺少新集合 quorum 的 Joint/Stable 后存在残留权限。 |

## 2. 整改设计

1. 新增 `ucn_cluster_authority_runtime_preflight(runtime, now_ms)`。未安装 Owner 时是 legacy no-op；已安装 Owner 时复用同一 bounded Owner 状态机，可能在本次入口直接撤权、进入 Grace 或 Fence。
2. `cluster_transmit()` 在 token bucket 前执行 preflight；这样过期 Authority 不会发帧，也不会消耗控制 token。
3. `ucn_cluster_receive()` 在严格解码、来源校验完成后、`messages_received` 与所有 Head handler 前执行 preflight。对已管理且非 active 的本地 Head，`JOIN_REQUEST`、`KEEPALIVE`、`LEAVE` 及 Head-consumed Backup 控制帧直接 `UCN_ERR_ACCESS`，不分配/续租/移除 member。
4. Federation 的 `step()`、`query_locator()`、公共 `publish_handover()` 在取得当前时钟后执行 preflight。受控 Owner 失权后，locator 注册、撤销、handover 和 Head query 无法以旧缓存继续写 Directory。
5. `install_config()` 改为 `install_config(runtime, config, now_ms)`：先在候选 Config/保留 lease 上计算 Stable 或 Joint 双 quorum；完成全部验证后一次提交。先清旧 active，再在满足 candidate quorum 时重新授予；不满足立即 `HEAD_QUORUM_GRACE`。

## 3. 新增回归

| 场景 | 断言 |
|---|---|
| 过期后先 Cluster Step/TX | Owner budget 超时直接 Fence；无 send、token bucket 字节不变。 |
| 过期后先 `JOIN_REQUEST` | RX preflight 先撤权；返回 `UCN_ERR_ACCESS`，primary member table、token、send 均不变。 |
| 过期后先 Federation public handover/step | public handover 返回 `UCN_ERR_ACCESS`；随后 step 无 locator/handover send，local locator 不产生 withdrawal 写。 |
| active → 无 quorum Joint | 立即 `authority_active=false`、`HEAD_QUORUM_GRACE`，Head/Backup Authority TX 均拒绝。 |
| active → 无 quorum Stable | 与 Joint 相同，证明不是只修复 Joint 特例。 |
