# 06 · 参数配置方案与 MCU 内存预算（全场景矩阵）

> 方法：GCC 实测 sizeof 全部关键结构体（6 组配置编译验证），按公式推导各场景组合。
> 全部为**静态 RAM 理论值**（不含栈/代码 Flash/介质驱动缓冲）；超标配置也给出真实值供参考。

## 3. 联动约束（编译期断言，改参数必须同步调整）

| 断言 | 公式 | 含义 |
| --- | --- | --- |
| 维护服务上界 | (BURST+1)×STEP×NEIGHBORS×BEARERS < SUSPECT | 业务突发不能让心跳饿死 |
| 默认 | 5×10ms×N×2 + 1000ms < 3000ms → **N×100ms < 2000ms → N ≤ 20** | 8 邻居默认余量足 |
| fast liveness | 5×10ms×N×2 + 250ms < 1250ms → **N×100ms < 1000ms → N ≤ 10** | 16 邻居必须调 fast 超时（实测编译失败） |
| 解法 | 调大 SUSPECT/REMOVE 或调小 STEP（如 5ms） | 大配置必做 |

## 4. 全场景配置矩阵（推荐参数 + 内存理论值）

### 场景 1：最小传感器节点（2-4 节点一跳）
- 目标：电池传感器，8 位/小型 32 位 MCU
- 参数：NANO Profile；帧 128B；2 Link；4 邻居；4 路由；2+2 队列；去重 8；Service OFF；无 Transfer
- Node RAM ≈ **3.0 KB**；附加（2 Link 80 + RX 队列 600）≈ 0.7 KB；**总 ≈ 3.7 KB**
- 适用：STM32G0、AVR、EFM8；**总 Flash 需求 ~15-20 KB**

### 场景 2：小型编队/家庭网（8-16 台）
- 目标：8-16 节点两跳内互控
- 参数：LITE Profile（省 Policy/Path/诊断 ~2.3KB）；帧 256B；4 Link；8 邻居；8 路由；4+4 队列
- Node RAM ≈ **6.0 KB**；附加（4 Link 160 + RX 600 + Service 可选 1.5KB）≈ 0.8~2.3 KB；**总 ≈ 6.8~8.3 KB**
- 适用：STM32F0/F1/G4、ESP32-C3

### 场景 3：中型网络 32 台（FULL 默认）
- 目标：32 节点 2-3 跳，诊断/路径/策略全开
- 参数：FULL 默认（8 邻/4 Link/8 路由/4+4/8 候选/8 Path/8 Policy）
- Node RAM ≈ **10.1 KB**；附加（4 Link 160 + RX 600 + Transfer 8.8K 可选 + Service 1.5K + Event 0.4K + Stream 1.0K）≈ 0.8~12.5 KB；**总 ≈ 10.9~22.6 KB**
- 适用：STM32F4/F7、ESP32、RP2040

### 场景 4：50 架无人机编队（分层，地面站/僚机同配置）
- 目标：1 地面站 + 4 区域控制器 × 8 僚机 = 32~50 台精准控制；10Hz 遥测
- 参数：FULL；帧 256B；**8 Link**（地面站接 8 台/控制器）；**16 邻居**；**16 路由**；8+8 队列；去重 64；候选 16；诊断开；Transfer 可选（T1K 即可：改 UCN_TRANSFER_MAX_MESSAGE_BYTES=1024 → RX 槽 1032B）
- 约束联动：16 邻居需调 fast liveness（FAST_SUSPECT=3000ms/FAST_REMOVE=4000ms/FAST_HEARTBEAT=500ms）
- Node RAM ≈ **13.5 KB**；附加（8 Link 320 + RX 600×2 + Transfer T1K ~1.9K + Service 1.5K + Event 0.4K + Stream 1.0K）≈ 5.7 KB；**总 ≈ 19 KB**
- 适用：ESP32-S3、STM32H7、nRF52840

### 场景 5：100 节点工厂传感器网（分层汇聚）
- 目标：100 节点，区域网关 8 叶子 × 12 网关，两跳
- 参数：FULL；帧 256B；**8 Link；16 邻居；32 路由**；8+8 队列；去重 64；候选 16；Path/Policy 16；RREQ 预算调大（RX_TOKEN_BURST=8/REFILL=100ms）
- 约束联动：16 邻居调 fast liveness（同上）
- Node RAM ≈ **19 KB**；附加（Transfer T2K 2.2K + Service 1.5K + Event 0.4K + Stream 1.0K + 8 Link 320 + RX 600）≈ 6.0 KB；**总 ≈ 25 KB**
- 适用：ESP32、STM32H7、i.MX RT

### 场景 6：254 节点单域极限（W0 或混合档）
- 目标：单域 254 节点上限，分层汇聚
- 参数：FULL；帧 256B；**16 Link；32 邻居；64 路由**；16+16 队列；去重 128；候选 32；Path/Policy 32；RREQ 接收预算 = 5+1/50ms（100/s）；STEP=5ms；SUSPECT=5000/REMOVE=6000
- Node RAM ≈ **42 KB**；附加（Transfer 2+2 槽 17.2K + Service 1.5K + Event 0.4K + Stream/CAN 各 1K + 16 Link 640 + RX 600×2）≈ 23 KB；**总 ≈ 65 KB**
- 适用：ESP32-S3 + PSRAM、STM32H7 双 bank、RP2040 + 外部 RAM

### 场景 7：高密度星型（1 地面站多介质多机器人）
- 目标：地面站同时精准控制 8-16 台（多介质：4 UART + 4 ESP-NOW + ...）
- 参数：FULL；帧 256B；**16 Link**；16 邻居；16 路由；8+8 队列；每邻居 2 Bearer
- Node RAM ≈ **16 KB**；附加（16 Link 640 + RX 队列 4×600 + Event 0.4K + Stream 4×1K）≈ 7.2 KB；**总 ≈ 23 KB**
- 适用：ESP32-S3（多 UART + ESP-NOW）

### 场景 8：高频控制（深队列小帧）
- 目标：8 台 × 100Hz 独立控制（10ms 内 8 条命令）
- 参数：FULL；**帧 128B**（命令 33B 帧 W0）；**16+16 队列 + 16 pending**；8 路由；8 邻居
- Node RAM ≈ **10.5 KB**；附加（Transfer 可选 1.9K + RX 600×2）≈ 3.1 KB；**总 ≈ 13.6 KB**
- 说明：16 槽 × 10ms = 160 帧/s 峰值 → 8 台 × 20Hz 稳定；Event Runtime 多轮可再翻倍

### 场景 9：大消息传输（OTA/日志）
- 目标：T8K 固件块下发，双槽并发
- 参数：FULL 默认 + **Transfer 2TX+2RX 槽、4-8 peers**；帧 256B
- 附加增量：2+2 槽 = 17.2 KB（1+1 槽 = 8.8 KB）；**总 ≈ 19~28 KB**（在场景 3 基础上）
- 说明：RX 槽是 8K 静态缓冲，是 RAM 大头；仅目标端节点开

### 场景 10：深跳网络（16-32 跳链）
- 目标：链式 16-32 跳长链
- 参数：FULL；**UCN_MAX_HOPS=32**（不占 RAM）；32 路由；16 邻居；16+16 队列；STEP=5ms
- Node RAM ≈ **33 KB**；**总 ≈ 45-50 KB**
- 说明：跳数本身零 RAM 成本，但每跳泛洪开销指数增长，32 跳只适合稀疏链

### 场景 11：4096 节点 Harness 理论极限（模拟器级）
- 目标：模拟器全配置拉满，每节点全表
- 参数：512 帧；32 邻居；16 Link；64 路由；16+16 队列；128 去重；候选 32；Path/Policy/Flow 32；Transfer 2+2；诊断全开
- Node RAM ≈ **49.9 KB**；附加 ≈ 25 KB；**总 ≈ 75 KB/节点**
- 全网内存：4096 节点 × 75 KB ≈ **307 MB**（静态数组，仅 Host 模拟可行）

### 场景 12：服务繁重（多任务多服务）
- 目标：6 绑定全用 + 跨节点 Bridge + 防重放
- 参数：Service 6 绑定、Q0 4 槽、远程 Q0/Q1 满配；Bridge + validator + replay
- 附加：Router 1200 + Bridge 280 + 每绑定 inbox 4×52 ≈ **2.5 KB**（在任意场景上叠加）

## 5. 扩容公式（速查）

| 想提升 | 改参数 | RAM 成本 |
| --- | --- | --- |
| 一跳精准台数 | UCN_MAX_LINKS +1 | +40B（Link）+ 邻居相关 |
| 多跳精准台数 | UCN_MAX_ROUTES +1 | +56B |
| 邻居密度 | UCN_MAX_NEIGHBORS +1 | +112B + 预算槽 32B |
| 并发寻路 | UCN_MAX_ROUTE_DISCOVERIES +1 | +28B |
| 控制频率 | UCN_TX_Q0/Q1_DEPTH +1 | +260B（256 帧）/槽 |
| 防重复范围 | UCN_DUPLICATE_SOURCE_WINDOWS +1 | +32B |
| 大消息 | UCN_TRANSFER_RX_SLOTS +1 | +8232B（8K）/槽 |
| 帧大小 | UCN_MAX_FRAME_BYTES +1 | +12B/字节（12 个帧槽） |

## 6. 结论

- **最小可用（NANO 一跳）≈ 3.7 KB RAM**：8 位机/小型 32 位机可行
- **中型编队（FULL 默认）≈ 11~23 KB**：主流 MCU 均可行（ESP32 实测整机 42.8KB RAM 含驱动）
- **254 节点极限 ≈ 65 KB/节点**：需要大 RAM MCU 或 PSRAM
- **4096 节点理论 ≈ 75 KB/节点**：仅 Host 模拟（全网 307MB）
- 所有数字为**纯协议静态 RAM**；真实工程需叠加驱动缓冲、RTOS 栈（ESP32 实测全系统 ~43KB 起）
