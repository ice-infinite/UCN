## 3. 已关闭的跨文档歧义

### 3.1 C0 事务宽度

早期低开销候选存在 32-bit 与 64-bit 控制事务两种写法。当前唯一规则是：C0 属于低频控制面，
统一使用 64-bit `C0TransactionId`；Bootstrap 的双方 nonce 仍是独立密码新鲜性输入。该选择只改变
C0，不增加 C1～C5 稳态数据开销。

### 3.2 Wire 长度

当前精确公式是共同 3 B Header 加 Contract Body、可选 Origin Tag 和可选 Hop Trailer。A1 下：

```text
C0 = 29 B    C1 = 13 B    C2 = 9 B
C3 =  7 B    C4 = 11 B    C5 = 13 B
```

以上为未附加 O/H 安全开销的基础头。旧 RFC 中已经标记失效的 41～47 B 统一大 Header 不能再作为
平级候选；现有完整 V6 的旧 Wire 实现也不能反向覆盖此冻结。

### 3.3 完整性职责

Core Packet 不重复携带 Carrier 已经提供的 Magic、总长度或通用 FCS。Origin/Hop 密码完整性只在
相应安全模式中出现；若 Carrier 本身不提供误码检测，Adapter/Bearer 合同必须显式提供等价保护，
不能偷偷把固定 CRC 加回所有 Core Packet。

### 3.4 Persistence 边界

Foundation 只保证一个不透明业务 Body 的原子记录、anti-rollback 和 durable proof，不解释业务
状态机。Cluster、Security、Operation 等 Record Body 必须在各自实现前单独冻结；这避免共同层
为了“将来可能需要”而永久携带所有模块字段。

## 8. 已关闭的 B04/B06/B07 生产基线整改与 B08 候选内容冻结

### V6S-B04｜CLOSED｜MSVC `/W4 /WX` 的已验证窄化

`ucn_v6_bootstrap_logical_encode()` 已通过 `evidence_is_valid()` 把长度限制在 `1..128`，但
`ucn_v6_bootstrap_evidence_t.length` 是 `uint16_t`，线上 length 字段为 `uint8_t`。当前赋值没有
显式窄化，MSVC 19.29 在生产 `src/v6/identity/ucn_v6_bootstrap.c` 报 C4244 并因 `/WX` 停止构建。

当前已在既有上界验证后使用显式 `uint8_t` 转换，并增加编译期 `MAX<=UINT8_MAX` 约束、128/129
边界和 MSVC Identity 定向回归。B04 不再阻断。

### V6S-B06｜CLOSED｜MSVC Security selector 的 definite-assignment

完整 MSVC 构建继续到 `ucn_v6_security_resolve_ingress_peer()` 后，在输出 `resolved` 时曾报告
C4701。源码逻辑用 `matched` 保证匹配后才写输出，但 MSVC 不能从循环和布尔门禁证明局部对象
必然已经赋值。

当前已初始化该 16 B 局部对象，并补零匹配不写回、唯一匹配和冲突 selector 持久快照拒绝回归。
MSVC Full Profile、Realtime/Cluster/Adapter OFF 的 Security 构建及测试 1/1 通过；没有降低
`/W4 /WX`。B06 不再阻断。

### V6S-B07｜CLOSED｜MSVC Runtime definite-assignment 与成功输出复核

完整 MSVC Full 构建曾在 `src/v6/runtime/ucn_v6_runtime.c` 对 `response_phase`、`enqueue`、
`disposition`、`record`、`relay_domain`、`buffer_token` 六个有界局部结果报告 C4701。逐处核对后，
它们都只在对应生产者成功后使用；当前显式初始化这些小型 staging，不压低编译器警告。

为避免初始化掩盖“生产者错误返回成功却没有写合法输出”，Capability 分支显式要求 disposition
属于 `MATCHED/QUERY_REQUIRED`，Route 分支显式验证最终 endpoint session。QoS 已有
`enqueue.accepted` 成功门禁，Bootstrap phase、Capability record、Route selection 与 Realtime token
也分别由既有合法性校验/下游入口拒绝零或无效值。MSVC Full Release `/W4 /WX` 完整构建与
CTest 28/28 通过，GCC Full/Lite/Nano、Nano Feature-OFF 和 Clang Full 也全部回归通过。
