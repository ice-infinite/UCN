# CLV2-05-09 外审 P1 整改计划（2026-08-22）

## 外审事实

原 40 B Carrier 回归只断言 payload length 与首字节。它无法检测末尾截断、字节错位或 Classic CAN 重组顺序错误，故“完整交付”结论证据不足。

## 整改范围

1. Stream/CAN 接收 fixture 保存完整、固定上界的 payload 副本及捕获有效标记；
2. Stream、CAN-FD、Classic CAN 三条 40 B 回归均以 `memcmp` 精确验证 40 个字节；
3. CAN-FD 固定验证 W0 57 B 之后的 7 B padding 全零，并将其中一字节置非零，验证 source 拒绝且不交付 endpoint；
4. 不修改 v3 Cluster codec、生产 Cluster send/receive/FSM、v4 encoder 或 Adapter 生产行为。

## 完成判据

- 三个正常路径均有完整内容相等断言；
- CAN-FD padding 的零值与非零拒绝路径都有独立断言；
- Full/Lite/Nano、MSVC、ASan/UBSan、analyzer 通过；
- 独立扫描继续证明 v4 未接入生产 Cluster RX/TX/FSM，M05 保持 `AUDIT HOLD`。
